# 🎨 Color Palette Generator

## 📖 About This Project

This project is part of the **JavaScript Starter Projects** collection.

You are given **only HTML and CSS**.
Your task is to write the **JavaScript** that makes this color palette interactive.

This project focuses on **DOM manipulation, events, and basic logic**.

---

## 🧩 What’s Already Provided

* ✔️ Complete HTML structure
* ✔️ Styled UI using CSS
* ❌ No JavaScript functionality

You must **add JavaScript without changing HTML or CSS**.

---

## 🎯 Features You Need to Implement

### 1. Generate Random Color

When the user:

* clicks **Generate Color**
* OR presses the **G** key

You should:

* generate a random HEX color (example: `#A1B2C3`)
* apply the color to the `.colorBox`
* update the `.hex` text with the new color

---

### 2. Copy Color Code

When the user:

* clicks **Copy HEX**
* OR presses the **C** key

You should:

* copy the current HEX color to the clipboard
* give visual feedback (optional but recommended)

---

### 3. Lock / Unlock Color

When the user clicks **Lock**:

* the color should stay fixed
* generating a new color should not work

When clicked again:

* unlock the color
* allow color generation

---

## 🧠 Concepts You Will Practice

By completing this project, you’ll practice:

* Selecting DOM elements
* Handling click events
* Handling keyboard events
* Generating random values
* Updating styles using JavaScript
* Updating text content
* Managing state with variables
* Using browser clipboard API

---

## 🛠 Suggested Steps (Don’t Skip!)

1. Select all required elements using JavaScript
2. Create a function to generate HEX colors
3. Update UI when a color is generated
4. Add event listeners to buttons
5. Add keyboard shortcuts (`G` and `C`)
6. Implement lock logic using a boolean variable

---

## ⚠️ Rules

* 🚫 Do not change HTML (You can add selectors if required)
* 🚫 Do not change CSS
* ✅ Write clean and readable JavaScript
* ✅ Use meaningful variable names
